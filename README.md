Landing page fictícia criada para fins de portfólio.

- styles.css
- script.js

- Escritório, sócios, OAB, contatos e demais informações são fictícios.
- As imagens são carregadas externamente e exigem conexão com a internet.
- O design foi pensado para funcionar bem em desktop e mobile.
